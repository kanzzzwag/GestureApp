# GestureApp — Development Plan & Guidelines

## Обзор проекта
GestureApp — десктопное приложение для управления системой и браузером с помощью мимики и жестов лица (на базе OpenCV и MediaPipe). Проект работает на асинхронной архитектуре (Tasks API), что обеспечивает плавную работу без блокировки видеопотока.
В данный момент реализованы три триггера: Двойное моргание (Double blink), Открывание рта (Mouth opening) и Улыбка (Smile).

## Текущая задача
Расширить функционал распознавания лица, добавить систему конфигурации для пользователя, разработать графический интерфейс (GUI) и создать инсталлятор для релиза на GitHub.

## Roadmap: План задач для Claude Code

### Phase 1: Расширение библиотеки жестов (Gesture Expansion)
Текущие жесты: Double blink, Mouth opening, Smile.
Необходимо добавить вычисление метрик для новых жестов с помощью MediaPipe Face Mesh:
- [ ] **Поднятие бровей (Eyebrow Raise):** Вычисление расстояния между глазами и бровями.
- [ ] **Подмигивание (Wink):** Раздельное вычисление EAR для левого и правого глаза.
- [ ] **Наклон/поворот головы (Head Tilt / Gaze):** Отслеживание положения головы влево/вправо/вверх/вниз.
- [ ] Оптимизировать функцию распознавания, чтобы избежать ложных срабатываний при одновременных жестах.

### Phase 2: Система конфигурации (User Config)
Пользователь должен сам настраивать триггеры и действия без изменения кода.
- [ ] Создать менеджер конфигурации (`config.json` или `config.yaml`).
- [ ] Реализовать маппинг "Жест -> Действие". (Например: "Улыбка" -> "Play/Pause", "Двойное моргание" -> "Закрыть вкладку").
- [ ] Вынести в конфиг технические параметры: индекс камеры, чувствительность (threshold) для каждого жеста (EAR, MAR и т.д.), задержки (cooldown).
- [ ] Генерация дефолтного файла настроек при первом запуске.

### Phase 3: Графический интерфейс пользователя (GUI)
- [ ] Интегрировать UI-фреймворк (CustomTkinter или PyQt6), совместимый с Tasks API.
- [ ] **Home:** Кнопка Start/Stop распознавания, индикатор статуса веб-камеры, мини-превью с камеры (с возможностью отключения).
- [ ] **Settings:** Интерфейс для редактирования `config.json`. Выпадающие списки для привязки жестов к кнопкам клавиатуры/мыши. Ползунки для регулировки чувствительности (позволяет юзеру настроить, насколько широко нужно открыть рот или улыбнуться для срабатывания).
- [ ] **System Tray:** Сворачивание в трей при закрытии окна (используя `pystray`), меню в трее.

### Phase 4: Отладка, Сборка и Инсталлятор (Deployment)
Проект должен быть готов к загрузке в раздел Releases на GitHub.
- [ ] Добавить глобальное логирование в файл (`app.log`) и безопасную обработку отключения веб-камеры.
- [ ] Сборка проекта в единый `.exe` файл с помощью `PyInstaller` (в режиме `--noconsole` с иконкой).
- [ ] Написать скрипт для Inno Setup (`.iss`), чтобы создать инсталлятор.
- [ ] Требования к инсталлятору: установка в `Program Files`, создание ярлыка на рабочем столе, опциональное добавление в автозапуск.

## Инструкции для агента (Claude Code)
1. **Фокус на одном:** Выполняй задачи строго по порядку. Не переходи к GUI, пока не добавлены новые жесты (Phase 1) и не протестирована конфигурация (Phase 2).
2. **Асинхронность:** При создании GUI убедись, что главный цикл окна (mainloop) корректно работает вместе с Tasks API и не блокирует обработку MediaPipe.
3. **Безопасные тесты:** После каждого добавления нового жеста проси пользователя протестировать его чувствительность.
4. Добавляй docstrings и комментарии к новым функциям и математическим расчетам расстояний между лендмарками.
